## How I work

1. **Plan**: define the problem, the user, and what "good" looks like before building.
2. **Build**: small, readable steps with clear commits.
3. **Test and iterate**: try it on real cases and improve it until it works reliably.
4. **Launch**: ship a ready-to-use tool and explain the choices and trade-offs to the people who will use it.
